# 一、顺序容器（Sequence Containers）

## `array`

**是什么**

- 固定长度的连续数组，大小在编译期确定
    

**典型用途**

- 小规模常量数组
    
- 状态固定的 DP 表
    
- 结构体内成员（替代裸数组）
    

**常见算法 / 场景**

- 枚举
    
- 小规模 DP
    
- 排序（规模很小）
    

**时间复杂度**

- 随机访问：`O(1)`
    
- 修改：`O(1)`
    

**空间特性**

- 无额外开销
    
- 连续内存，最省空间
    

---

## `vector`

**是什么**

- 动态长度的连续数组，是竞赛最通用的容器
    

**典型用途**

- 普通数组
    
- 邻接表
    
- DP 数组
    
- 存储输入数据
    
- 离散化后的值集合
    

**常见算法 / 场景**

- 排序 + 二分
    
- 前缀和 / 差分
    
- 双指针
    
- DP
    
- 图遍历（邻接表）
    

**时间复杂度**

- 随机访问：`O(1)`
    
- 尾部插入：均摊 `O(1)`
    
- 中间插删：`O(n)`
    

**空间特性**

- 连续内存
    
- 有容量冗余（`capacity`）
    

---

## `deque`

**是什么**

- 支持两端高效操作的序列容器
    

**典型用途**

- 双端队列
    
- 滑动窗口
    
- 单调队列
    

**常见算法 / 场景**

- 区间最值维护
    
- 0-1 BFS
    
- 模拟队列 + 栈混合结构
    

**时间复杂度**

- 头尾插删：`O(1)`
    
- 随机访问：`O(1)`（常数偏大）
    

**空间特性**

- 分段连续
    
- 空间略大于 vector
    

---

## `list`

**是什么**

- 双向链表
    

**典型用途**

- 需要频繁在中间插入、删除（竞赛中极少）
    

**常见算法 / 场景**

- 特殊模拟题（非常罕见）
    

**时间复杂度**

- 插入 / 删除：`O(1)`
    
- 查找 / 访问：`O(n)`
    

**空间特性**

- 指针多
    
- 空间浪费大
    

---

## `forward_list`

**是什么**

- 单向链表
    

**典型用途**

- 理论存在，竞赛几乎不用
    

**时间复杂度**

- 插删：`O(1)`
    
- 访问：`O(n)`
    

**空间特性**

- 比 list 稍省
    
- 实用性很低
    

---

## `string`

**是什么**

- 专门为字符串优化的顺序容器
    

**典型用途**

- 文本处理
    
- 模式匹配
    
- 字符串比较
    

**常见算法 / 场景**

- KMP / Z / Manacher
    
- 字符串哈希
    
- 双指针
    

**时间复杂度**

- 访问：`O(1)`
    
- 拼接：均摊 `O(1)`
    
- 子串：`O(len)`
    

**空间特性**

- 连续内存
    
- 小字符串优化（SSO）
    

---

# 二、有序关联容器（红黑树）

## `set`

**是什么**

- 自动排序、去重的集合
    

**典型用途**

- 动态维护有序元素
    
- 快速找前驱 / 后继
    
- 判重 + 排序
    

**常见算法 / 场景**

- 贪心选择
    
- 扫描线
    
- 区间合并
    
- 维护当前最小 / 最大合法值
    

**时间复杂度**

- 插入 / 删除 / 查找：`O(log n)`
    

**空间特性**

- 树结构
    
- 空间开销较大
    

---

## `multiset`

**是什么**

- 允许重复元素的有序集合
    

**典型用途**

- 需要有序 + 可重复的数据结构
    
- 多重计数
    

**常见算法 / 场景**

- 中位数维护
    
- 滑动窗口统计
    
- 贪心中维护多个相同值
    

**时间复杂度**

- 插删查：`O(log n)`
    

**空间特性**

- 比 set 更大
    

---

## `map`

**是什么**

- 有序的键值映射（key → value）
    

**典型用途**

- 按 key 自动排序的字典
    
- 统计并保持顺序
    
- 区间信息存储
    

**常见算法 / 场景**

- 离线统计
    
- 贪心 + 状态映射
    
- 区间合并（key 为左端点）
    
- 扫描线
    

**时间复杂度**

- 插入 / 删除 / 查找：`O(log n)`
    

**空间特性**

- 红黑树节点
    
- 常数较大
    

---

## `multimap`

**是什么**

- 允许多个相同 key 的 map
    

**典型用途**

- 一对多关系（竞赛极少）
    

**时间复杂度**

- 插删查：`O(log n)`
    

**空间特性**

- 最大
    

---

# 三、无序关联容器（哈希）

## `unordered_set`

**是什么**

- 基于哈希的集合，不保证顺序
    

**典型用途**

- 快速判重
    
- 记录出现过的状态
    

**常见算法 / 场景**

- BFS / DFS 判重
    
- 状态压缩
    
- 哈希集合运算
    

**时间复杂度**

- 均摊：`O(1)`
    
- 最坏：`O(n)`
    

**空间特性**

- 哈希桶
    
- 空间较大
    

---

## `unordered_multiset`

**是什么**

- 可重复的哈希集合
    

**典型用途**

- 很少用
    

**时间复杂度**

- 均摊 `O(1)`
    

**空间特性**

- 很大
    

---

## `unordered_map`

**是什么**

- 基于哈希的键值映射
    

**典型用途**

- 快速计数
    
- 映射复杂状态
    
- 离散化映射
    

**常见算法 / 场景**

- 哈希统计
    
- 记忆化搜索
    
- 状态 DP
    
- 前缀和计数
    

**时间复杂度**

- 均摊：`O(1)`
    
- 最坏：`O(n)`
    

**空间特性**

- 较大
    
- 需要预留容量
    

---

## `unordered_multimap`

**是什么**

- 哈希一对多映射
    

**典型用途**

- 几乎不用
    

---

# 四、容器适配器

## `stack`

**是什么**

- 后进先出结构
    

**典型用途**

- 保存历史状态
    
- 表达式计算
    

**常见算法 / 场景**

- 单调栈
    
- DFS 模拟
    

**时间复杂度**

- 所有操作：`O(1)`
    

---

## `queue`

**是什么**

- 先进先出结构
    

**典型用途**

- 层序处理
    

**常见算法 / 场景**

- BFS
    
- 拓扑排序
    

**时间复杂度**

- 所有操作：`O(1)`
    

---

## `priority_queue`

**是什么**

- 基于堆的优先队列
    

**典型用途**

- 动态维护最大 / 最小值
    

**常见算法 / 场景**

- Dijkstra
    
- 贪心
    
- 多路归并
    

**时间复杂度**

- 插入 / 删除：`O(log n)`
    
- 取顶：`O(1)`
    

---

# 五、特殊结构

## `bitset`

**是什么**

- 定长位集合
    

**典型用途**

- 位压缩
    
- 快速集合运算
    

**常见算法 / 场景**

- 位 DP
    
- 状态压缩
    
- 子集运算
    

**时间复杂度**

- 位运算：`O(n / word_size)`
    

**空间特性**

- 极省
    
- 编译期定长
    

---

## `pair`

**是什么**

- 二元数据结构
    

**典型用途**

- 存边
    
- 状态封装
    
- 排序键
    

**常见算法 / 场景**

- 图
    
- DP
    
- 排序
    

**时间复杂度**

- 访问：`O(1)`
    

---

## `tuple`

**是什么**

- 多元数据结构
    

**典型用途**

- 复杂状态表示
    

**常见算法 / 场景**

- 高维状态
    
- 多关键字排序
    

**时间复杂度**

- 访问：`O(1)`（常数较大）
