# 查找
>  \[需要包含algorithm\]
- `auto it = find(T.begin(),T.end(),value)` 
	- `*it=value`
- `find_if(T.begin(),T.end(),[](T x)(return x.value>0;))` 
- `max/min(value1,value2,...) or ({value1,value2...})` 
- `max_element/min_element(T.begin(),T.end())` 
- `unique(T.begin(),T.end())` 
- `auto [min,max] = minmax/minmax_element(...)`
- `auto result = minmax/minmax_element(...)`
	- `result.first or result.second`
## 二分查找
- `upper_bound(T.begin(),T.end(),value)` - `>value`
- `lower_bound(T.begin(),T.end(),value)` - `>=value`
## 统计
- `count(T.begin(),T.end(),value)` 
- `count(T.begin(),T.end(),[](T x)(return x.value>0;))` 
# 删除
- `T.clear()` - delete all
	- `T.shrink_to_fit()` - free memery
- `T.erase(T.begin())`
- `T.erase(T.begin(),T.end())`
- `T.erase(std::remove(...))` - `remove与find格式类似`
# 排序
>  \[需要包含algorithm\]
- `sort(T.begin(),T.end())` - 升序
- `sort(T.begin(),T.end(),std::greater<int>())` - 降序 \[需要包含functional\]
- `sort(T.begin(),T.end(),[](const T &a,const T &b){return a.value<b.value})`
# 哈希表
>  \[需要包含unordered_map or set\]
- `unordered_map<int,int> map`
- `unordered_set<int> map` - `不存储值`
- `map[value]=count or ++--`
- `map.find(...)`
- `map.count(...)`
```c++
// 遍历哈希表
 for (const auto& pair : wordCount) {
    std::cout << pair.first << ": " << pair.second << std::endl;
}
```

# 移动语义
- `move(T)` - 直接移动内部指针，不用拷贝
