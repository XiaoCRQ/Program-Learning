# 背景
此题目会给出一个非常大的 `n`，通常 `n > 1e18`
但此时也会给出一个数据范围，即最大的质因数范围
自然而然的，我们就想到可以通过质因数求解
# 算法实现
- 求解质数表 —— 打表
>在实际算法中我们不可能在实际代码中实时计算质数有哪些，太过浪费时间
>可以通过计算机直接打表该范围内所有的质数输出到文件中，模板代码如下
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
  int n;
  cin >> n; // 输入最大值 | n = 最大值
  if (n < 2) {
    ofstream out("primes.txt");
    out << "{}\n";
    out.close();
    return 0;
  }

  vector<bool> is_prime(n + 1, true);
  is_prime[0] = is_prime[1] = false;

  for (int i = 2; i * i <= n; ++i) {
    if (is_prime[i]) {
      for (int j = i * i; j <= n; j += i) {
        is_prime[j] = false;
      }
    }
  }

  ofstream out("primes.txt");
  out << "{";
  bool first = true;
  for (int i = 2; i <= n; ++i) {
    if (is_prime[i]) {
      if (!first)
        out << ",";
      out << i;
      first = false;
    }
  }
  out << "}\n";
  out.close();
  return 0;
}
```
- 使用质因数求解因数数量
$$
n = p_1^{a_1} \times p_2^{a_2} \times \cdots \times p_k^{a_k}
$$
- 对于任何一个整数 `n` 都有以上公式
	- `p` 被当作因子的质数
	- `a` 质数被整除的次数
- 那么 `因子数 = (a1+1)*(a2+1)*(a3+1)*...*(ak+1)`
- 实现代码
```cpp
const ll p[]= {...} // 打好的质数表
int main() {
  fast_io();
  ll n, ans = 1;
  cin >> n;
  for (auto &it : p) {
    ll cnt = 1;
    if (it * it > n)
      break;
    if (n % it == 0) {
      while (n % it == 0)
        n /= it, cnt++;
      ans *= cnt;
    }
  }
  if (n > 1)
    ans *= 2;
  cout << ans;
  return 0;
}
```
