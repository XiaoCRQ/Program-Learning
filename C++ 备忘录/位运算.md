# 异或 `^`
1. 自反性 `a^b=b^a` `(a^b)^c=a^(b^c)`
2. 恒等律 `a^0=a`
3. 归零律 `a^a=0`
4. 奇偶保留
	1. 若一个数出现 `偶数次` 则结果为0
	2. 若一个数出现 `奇数次` 则结果为本身
5. 无临时变量交换
 ```cpp
a ^= b;
b ^= a; // b = original a
a ^= b; // a = original b
 ```
# 与 `&`
1. 判断奇偶 `n&1(1-奇,0-偶)`
2. 清楚最低位的`1` `n&(n-1)`
	1. 计算二进制中 1 的个数（Brian Kernighan 算法）
	2. 判断是否为 2 的幂：`(n > 0) && (n & (n - 1)) == 0`
